# Topuw&#39;s End Update

## Summary

Topuw's End Update is a Minecraft Java Edition mod focused on expanding and improving the End dimension.

The goal of this project is to make the End more interesting to explore by introducing new content, structures, and gameplay features while preserving the atmosphere of the original Minecraft experience.

Features:

End Ruins - Four variants of a new structure that can generate throughout the End.
Natural Endermite Spawning - Endermites can spawn naturally in the End, making the dimension more dynamic.
Bucket of Endermite - A new item that allows players to collect and transport endermites.

This project is actively being developed, and more features and improvements are planned for future updates.
